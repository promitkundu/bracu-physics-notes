# Brac University Physics Lecture Notes

This repository contains LaTeX-typeset PDF notes for undergraduate Physics courses at [Brac University](https://www.bracu.ac.bd/). 

As a physics student, I am translating my professor's handwritten lectures into clean, readable PDF documents to make studying easier and more accessible for my fellow students. 

## 📂 Repository Structure
The notes are organized by course. Inside each course folder, you will find the PDF notes along with details about the original faculty member who taught the course.

*Note: This repository only hosts the final, compiled `.pdf` files. The raw LaTeX source code (`.tex`) is kept private.*
